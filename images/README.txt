Put your photos in this folder, then update the matching <img> tag.

site-background.jpg is already here — it's the watercolor + logo
background used on every page. It's set in css/style.css on the
body rule. To swap it for a different image later, just replace
this file (keep the same name) or update the url() path in
css/style.css.

Home page (index.html)
  images/photo1.jpg      -> top photo in the photo stack
  images/photo2.jpg      -> bottom photo in the photo stack

About page (about.html)
  images/about-photo.jpg -> the group/event photo beside the text

Members page (members.html)
  images/members/president.jpg
  images/members/vice-president.jpg
  images/members/secretary.jpg
  images/members/treasurer.jpg
  images/members/auditor.jpg
  images/members/pio.jpg
  (name these however you like — just match the src in members.html)

Committees, Social Media, and Application pages don't need photos —
committees use emoji icons, social media uses drawn icons, and
application just links to your Google Form.

Each spot in the HTML is marked with a comment like:
  <!-- INSERT PHOTO HERE ... -->
so you can find them quickly by searching the files for "INSERT PHOTO".
